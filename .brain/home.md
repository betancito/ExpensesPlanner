# ExpensesPlanner brain

This folder is the project's Obsidian vault and durable memory. Keep notes concise, link related notes, and update them when decisions or work change.

## Resume here

1. [[current-handoff]] — current status, active work, and next action.
2. The initialization note for your role: [[init-planner]], [[init-dev]], or [[init-reviewer]].
3. The active feature linked from the handoff, if one exists.
4. Other notes only when the task needs them.

Do not bulk-read the vault or old session logs to start a session.

## Project memory

- [[project]] — product goals, constraints, and development environment.
- [[backlog]] — prioritized work and ideas.
- [[decisions]] — durable decisions and their reasons.
- [[features/feature-template]] — copy when planning a feature.
- [[reviews/review-template]] — copy for reviewer evidence.
- [[sessions/session-template]] — copy only for a session with durable outcomes.

## Rules

- The handoff and active feature are the working state; do not duplicate their status elsewhere.
- Record decisions when made, not just when a feature is complete.
- Never store financial records, credentials, signing keys, or other secrets in this vault.
- Use Obsidian wikilinks for navigation and kebab-case filenames for new notes.
